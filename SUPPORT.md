|---|---|
| [GitHub Issues](https://github.com/EgorLikhachev/SpeakerLab/issues) | Bug reports and feature requests |
| [GitHub Discussions](https://github.com/EgorLikhachev/SpeakerLab/discussions) | Questions, usage help, sharing designs |

| [CONTRIBUTING.md](CONTRIBUTING.md) | How to build and submit changes |

## Before You Ask

1. Check the [README](README.md) — it covers installation and common usage.
2. Search existing [issues](https://github.com/EgorLikhachev/SpeakerLab/issues)
   and [discussions](https://github.com/EgorLikhachev/SpeakerLab/discussions)
   for your question.
3. If you are reporting a calculation that looks wrong, please include:
   - The driver T/S parameters you entered
   - The enclosure type and its parameters
   - What the application shows vs. what you expected
   - Your operating system and app version

## Filing Good Bug Reports

Use the
[bug report template](https://github.com/EgorLikhachev/SpeakerLab/issues/new?template=bug_report.md)
— it asks for exactly the information needed to reproduce the problem
quickly. Attaching the `.spkproj` project file (it is plain JSON) usually
makes reproduction trivial.

## Security Issues

Do not report security issues publicly — see [SECURITY.md](SECURITY.md).
